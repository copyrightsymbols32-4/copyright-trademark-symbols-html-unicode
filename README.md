# Copyright & Trademark Symbols Cheat Sheet

Quick reference guide for developers, content creators, and designers needing standard legal characters, HTML entities, and keyboard shortcuts.

## Common Keyboard Shortcuts & Alt Codes

* **Copyright Symbol (©):** `Alt + 0169` (Windows) | `Option + G` (Mac)
* **Trademark Symbol (™):** `Alt + 0153` (Windows) | `Option + 2` (Mac)
* **Registered Symbol (®):** `Alt + 0174` (Windows) | `Option + R` (Mac)

## HTML Entities & Unicode

| Character | Name | HTML Entity | Unicode |
| :--- | :--- | :--- | :--- |
| **©** | Copyright | `&copy;` | `U+00A9` |
| **™** | Trademark | `&trade;` | `U+2122` |
| **®** | Registered | `&reg;` | `U+00AE` |
